# OpenScale

OpenScale is the firmware and web application project for the Half Decent Scale.

## Web applications

- [Shot Flow](shot-flow/shot_flow.html) visualizes espresso flow, yield, extraction time, target profiles, and saved shots using demo scale data.
- [Custom build configurator](custom-build/) creates firmware builds from supported features and plugins.

The Shot Flow demo data is available only on GitHub Pages and is not included in the scale filesystem.
